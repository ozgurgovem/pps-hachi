# What this step is for

State the gap between the standard and what's actually happening, in numbers. Not an opinion, not a symptom description — a measured difference between "should" and "is."

## What good looks like

A single sentence with a number, a unit and a baseline period: "Weld rejects on line 3 rose from 0.8% to 3.1% between week 22 and week 26." Anyone reading it six months later can tell whether the problem is still happening.

## Common failure modes

- No number — "quality has gotten worse lately" is not a problem statement, it's a complaint.
- A number with no baseline — 3.1% is meaningless without knowing what it used to be.
- A root cause smuggled into the problem statement — "rejects are high because the fixture is worn" assumes the answer before Step 4 asks the question.

## Worked example

Bad: "Too many bracket rejects on the Şişli line." Good: "Bracket weld rejects on the Şişli line rose from 0.8% (Jan–Mar average) to 3.1% (week 22–26), against a 1.0% standard."
