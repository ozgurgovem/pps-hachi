# What this step is for

Lock the fix into the way work is actually done, and spread it (yokoten) to every other line, shift or plant where the same failure could happen.

## What good looks like

At least one standard document — SOP, PFMEA, Control Plan, work instruction, checklist, training matrix, drawing, maintenance plan or inspection standard — is marked updated, and the read-across table names the other places this should apply.

## Common failure modes

- Fixing the line but never updating the Control Plan or PFMEA, so the next audit shows the documented process doesn't match reality.
- Leaving the yokoten table empty — the same failure mode is live on three other lines and nobody was told.
- Treating "we fixed it" as the end state instead of "we fixed it and it can't quietly un-fix itself."

## Worked example

Control Plan and PFMEA updated to require the weekly calibration check. Yokoten table: lines 4 and 7 use the same welder model — calibration check rolled out to both within two weeks, logged with sign-off.
