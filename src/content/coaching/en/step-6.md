# What this step is for

Turn the countermeasures from Step 5 into concrete actions and see them through — who does what, by when, and whether it actually happened.

## What good looks like

Every action has a named owner and a due date, and gets marked done only when it's actually done — not when it's been assigned. A plan with no owner is a wish.

## Common failure modes

- An action with no owner — everyone's responsibility is nobody's responsibility.
- No due date, so the action drifts indefinitely without anyone noticing it stalled.
- Marking an action "done" because it was started, not because it was verified complete.

## Worked example

Action: install the calibration poka-yoke on station 3. Owner: maintenance lead. Due: week 30. Status: done, verified by a floor walk on week 30 — the interlock physically blocks the cycle when calibration is overdue.
