# DECISIONS.md

One line per architectural decision: **date · decision · reason**. Append, never rewrite.
When we change our minds, add a new row that supersedes the old one and mark the old one
`SUPERSEDED by D-NN`. This file is the record an auditor — or a future session — reads to
find out *why*, not *what*.

Status values: `LOCKED` (do not relitigate without asking) · `OPEN` (decided but revisitable)
· `PENDING` (raised, not yet decided) · `SUPERSEDED`.

| D-20 | 2026-08-01 | **The app is fully functional with AI off.** Offline is the base product, not a fallback. | D-21 | 2026-08-01 | **Never hardcode model lists.** Fetch from each provider's models endpoint, cache 24 h, keep a small fallback in config. | D-22 | 2026-08-01 | **Zod schemas are the source of truth for types** — derive TS types from schemas, not the reverse. TypeScript strict, no `any`, no `@ts-ignore`. | One definition of shape, validated at every boundary. | LOCKED |

| D-24 | 2026-08-01 | **One phase at a time, per `SPEC.md` §6**; stop and show a runnable build at each phase boundary. Fresh session per phase. | An app this size drifts badly if built in one pass; clean context per phase is also the cheaper way to run it. | LOCKED |
